Prework: install before the workshop

Hello, and thank you for registering for our workshop on Wednesday 25 November 2026.

To make sure we don’t waste time on the day, please complete the setup below before the workshop if you can. It takes about 15 minutes. If you run into any problem, write to munich@codebar.io. If you can’t finish, don’t worry: bring your laptop and we will help you at the start.

What we do

We work with an AI agent called Iris. The workshop can be run with Claude (you need a paid account) or with OpenCode (free, no account). Choose one of the two below. If you don’t have a paid Claude account, choose OpenCode.

OPTION A · FREE

OpenCode

OpenCode comes with free models and needs no account. You can use the app with windows and buttons, or the terminal (command line). Pick whichever you prefer.

The app (recommended for Windows)

Download the OpenCode desktop app for macOS, Windows or Linux from opencode.ai/download and install it like any other program.

The terminal (Mac and Linux)

Open a terminal (see the box below), paste this line and press Enter:

curl -fsSL https://opencode.ai/v2/install | bash

Windows users: the OpenCode documentation does not support Windows package managers, so please use the app. Full instructions: opencode.ai/docs.

How to check it worked. App: open it, and it should start without an error message. Terminal: close the terminal, open a new one and type opencode --version. You should see a version number.
OPTION B · PAID CLAUDE ACCOUNT

Claude

You need a Pro, Max, Team or Enterprise account. The free Claude plan does not include Claude Code. Sign up at claude.com/pricing if you want to use it.

The app

Download the Claude desktop app from claude.com/download and sign in.

The terminal

Mac and Linux:

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

Then type claude and sign in with your Claude account when it asks. Full instructions: code.claude.com/docs/en/setup.

How to check it worked. In a new terminal, type claude --version. You should see a version number. In the app, you should be able to sign in.
How to open a terminal. Mac: press Cmd + Space, type Terminal and press Enter. Windows: press Win + X and choose Windows PowerShell or Terminal. Linux: open your terminal app. Paste with Cmd + V (Mac), Ctrl + V (Windows) or Ctrl + Shift + V (Linux).

Also useful

  • A code editor such as Visual Studio Code. It is free, and it lets you read and edit the files we work with. It is helpful, not required.
  • Your laptop and charger, and a working Wi-Fi connection. Windows, Mac and Linux are all fine.
  • A laptop where you can install programs. If your laptop belongs to your employer and blocks installs, please tell us in advance at munich@codebar.io.
  • No GitHub account is needed. We will give you the project files on the day.
Privacy. We only work with Iris, a fictional person with invented data. Please don’t use your own CV or personal details in the workshop. Free models may store what you send them.
